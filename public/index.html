01 / Parametric form

Twelve controlled alternatives.

Three floor counts × two tapers × two twists. Base dimensions, floor height and shade depth stay fixed.

Untwisted cases dominate their twisted counterparts under these two objectives. That does not decide spatial quality or architectural value.

Read the twelve cases and proxy assumptions

Illustrative factors: concrete 320 kgCO₂e/m³; facade 55 kgCO₂e/m²; shades 18 kgCO₂e/m². This limited proxy excludes foundations, columns, reinforcement, MEP, interiors and lifecycle stages. Shade openness is a geometric ratio, not a solar simulation.

Research / The next experiment
AI agents that can
resume the work.
Can the agents recover the right conditions, decisions and checks after a new conversation or a model revision?


Persistent project memory / Proposed
Save the decision
and the context behind it.
A shared project record would retain original clauses, conditions and exceptions, element IDs, model revisions, tool inputs and results. It would separate accepted decisions, proposals and unresolved questions.
Each agent would retrieve the records relevant to its task. A checkpoint would save completed steps and the next action; a conversation summary would link back to the records rather than replace them.

Example handoff After a beam edit, the agents would recover why a route was chosen, load the current requirement, rerun affected checks and explain the difference. Missing or conflicting records would trigger review.


Proposed next stage. Aether currently uses authored rules and deterministic calculations; persistent AI agents are not implemented. Saving records supports recovery, but correct retrieval and interpretation still need testing.




01 / Resume
Recover unfinished work.
Interrupt 20 design workflows across five sessions. Compare recent conversation context, rolling summaries and versioned project memory using the same model and task budget.
Measure
Recovered decisions, missed constraints, outdated facts, unsupported answers and recovery time.


02 / Retain
Keep the necessary condition.
Test 30 reviewed clauses containing conditions, exceptions and cross-references. Compare fixed-word chunks with linked requirement records under the same evidence budget, including missing and conflicting records.
Measure
Lost conditions, wrong element links, unresolved references and appropriate requests for review.


03 / Update
Catch a result that has gone stale.
Apply 40 controlled document and model edits. Compare name links, element IDs and versioned dependency links against a full recheck and human annotations.
Measure
Missed affected checks, stale passes and unnecessary rechecks. Review disputed cases with architects and engineers.




These are proposed experiments, with planned sample counts rather than completed results. The aim is measurable continuity across sessions and revisions. I want to develop this investigation towards a PhD in architectural computation.
